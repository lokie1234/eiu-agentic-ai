CÁCH TRIỂN KHAI:
1. Giải nén ZIP; đưa file/thư mục BÊN TRONG Cloudfare--main lên repository GitHub của bạn.
   Nếu repo đã tồn tại, ghi đè đúng các file đã thay đổi. Không upload file ZIP như một file chạy web.
2. Quan trọng: copy apps-script/Code.gs sang dự án Google Apps Script đang chạy và tạo NEW VERSION của deployment /exec.
3. Cloudflare Pages sẽ build lại từ GitHub. Giữ nguyên secrets APPS_SCRIPT_URL, APPS_SCRIPT_API_KEY và cấu hình build: public.
4. Kiểm tra đăng ký thử, học phí Google Sheet, email, VietQR, mobile và ngày hết hạn.

Lưu ý: JS ở trình duyệt chỉ hỗ trợ hiển thị; backend Apps Script mới là nơi quyết định học phí cuối cùng.
